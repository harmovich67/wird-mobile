# وِرد (Wird) — تطبيق الجوال بنظام React Native & Expo

تطبيق إسلامي ذكي مخصص لحفظ القرآن الكريم والأحاديث النبوية ومراجعتها، مبني بالكامل بنظام **React Native** و **Expo** مع واجهة عربية أصيلة وأسلوب إسلامي ملكي بألوان الزمرد والذهب.

---

## 🌟 أبرز مميزات التطبيق

1. **اسبلاش سكرين مميز وأصيل (Distinctive Animated Splash Screen)**:
   - خلفية ملكية بتدرجات الزمرد العميق والذهب المشع.
   - دوران انسيابي للزخرفة الهندسية الإسلامية (النجمة الثمانية / ربع الحزب).
   - وميض الهالة النورانية وحبيبات الذهب المتطايرة بـ 60 إطاراً في الثانية.
   - شعار وِرد الأصيل: المصحف الشريف المفتوح وترددات الترتيل الصوتية.
   - آية قرآنية كريمة ملهمة: « وَرَتِّلِ الْقُرْآنَ تَرْتِيلًا ».
   - شريط تقدم ذهبي وانتقال سلس للشاشات الرئيسية مع خيار الدخول المباشر.

2. **الرئيسية ولوحة الإنجاز اليومي (Dashboard)**:
   - حلقة إنجاز الورد اليومي ومتابعة نسبة الإتمام.
   - عداد أيام التتابع والالتزام المستمر (Streak Counter 🔥).
   - قائمة مراجعات اليوم الذكية مع زر الانطلاق الفوري.
   - شبكة سريعة لكافة الأقسام والخدمات.
   - آية وتدبر لليوم مع إمكانية الفتح في المصحف وإضافتها للورد.

3. **المصحف الشريف (Holy Quran Reader)**:
   - فهرس كامل لكافة سور القرآن الكريم (١١٤ سورة) مع بيانات النزول (مكية / مدنية) وعدد الآيات.
   - بحث فوري باسم السورة أو رقمها.
   - قارئ الآيات بالرسم العثماني.
   - استماع صوتي مباشر لكل آية بصوت الشيخ مشاري العفاسي.
   - زر «أضف للورد» لإدراج أي آية مباشرة في نظام التكرار المتباعد للحفظ.

4. **جلسة الحفظ الذكي والتكرار المتباعد (Spaced Repetition SM-2)**:
   - خوارزمية SuperMemo-2 المعتمدة في تثبيت الحفظ:
     * 🔴 **نسيت (Forgot)**: إعادة الورد لمرحلة التثبيت الأولى (يوم واحد).
     * 🟠 **صعب (Hard)**: زيادة طفيفة في المدة مع تثبيت الذاكرة.
     * 🟢 **جيد (Good)**: مضاعفة الفترة وفق معامل السهولة (Ease Factor).
     * ⭐️ **سهل (Easy)**: قفزة متقدمة نحو التمكين والإتقان الكامل.
   - أوضاع الحفظ النشط (Active Recall):
     * **وضع القراءة والتأمل**: النص كاملاً واضحاً.
     * **وضع الإخفاء التدريجي (Progressive Hiding)**: إخفاء ٢٥%، ٥٠%، ٧٥%، أو ١٠٠% من الكلمات مع إمكانية النقر على أي كلمة لكشفها سريعاً.
     * **وضع التسميع والكتابة (Recall & Type)**: كتابة النص من الحفظ مع احتساب نسبة المطابقة والدقة تلقائياً.

5. **السنة النبوية الشريفة (Hadith)**:
   - أحاديث متن الأربعين النووية كاملة (٤٢ حديثاً).
   - روائع وبواكير من صحيح الإمام البخاري.
   - إمكانية حفظ أي حديث وإضافته لجدول المراجعة بنقرة زر.

6. **أحكام التجويد التفاعلية (Tajweed Guide)**:
   - تصنيف شامل: أحكام النون الساكنة والتنوين، الميم الساكنة، القلقلة، والمدود.
   - بطاقات تفاعلية مع حروف كل حكم وأمثلة قرآنية صريحة.
   - دليل ألوان المصحف المجود المعتمد عالمياً.

7. **الأذكار والسبحة الرقمية (Adhkar & Digital Tasbeeh)**:
   - أذكار الصباح، المساء، النوم، وأذكار ما بعد الصلاة مع فضل كل ذكر.
   - عداد لمس ذكي ينقص حتى الصفر مع اهتزاز لمسي (Haptic Feedback).
   - سبحة إلكترونية رقمية كبيرة لا محدودة أو بأهداف (٣٣، ٩٩، ١٠٠) مع إمكانية تصفير العداد وتغيير صيغ التسبيح.

8. **الإعدادات والتخصيص (Settings)**:
   - تحديد الهدف اليومي للوقت والمراجعات.
   - التحكم في حجم خط المصحف وألوان التجويد والاهتزازات.
   - خيار إعادة ضبط وتصفير البيانات عند الحاجة.

## 🚀 تشغيل المشروع وتجربته

### ١. التوجه لمجلد المشروع
```bash
cd wirdy-mobile
```

### ٢. تشغيل التطبيق في بيئة التطوير
```bash
npx expo start
```
أو عبر الخيارات المباشرة:
- **لتشغيل الويب**: `npm run web` أو `npx expo start --web`
- **لتشغيل الأندرويد**: `npm run android` أو عبر تطبيق **Expo Go** على هاتفك بمسح كود الـ QR
- **لتشغيل الآيفون**: `npm run ios`

### ٣. بناء حزمة أندرويد نهائية (APK / Bundle)
```bash
npx eas build -p android --profile preview
```
أو تصدير الحزمة الثابتة:
```bash
npx expo export -p android
```
